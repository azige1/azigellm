#### 项目一：从真实代码仓库合成函数级编程任务与等价性判分
**项目背景**：编程 Agent 的评测与短程训练需要大量可自动判分的函数级编程任务；由模型自造题时，期望输出也由模型预测，非平凡函数的期望值错误无法核查。项目从 210 余个开源 Python 仓库抽取约 4.6 万个函数，为每个函数合成以参考实现为基准的判分测试与自然语言规格，产出 1.4 万条逐条经沙箱验证的任务，测试一次执行通过率由 58% 提升至 74%。本人负责等价性判分与依赖切片两个模块，参与插桩采集与多轮反馈生成的实现。  
**参考实现作 oracle 的等价性判分**：测试不写字面期望值，只断言候选实现与参考实现在同一组输入下的返回值、异常类型与消息一致，替代由模型预测期望输出的写法，消除期望值写错造成的误判。每条新测试先在参考实现上执行，未通过即判为测试自身缺陷并拦截，拦截约 7%；同批 800 个函数对照，抽检缺陷率由 28% 降至 1.9%。  
**语句依赖图与调用图的依赖切片**：从目标函数出发，在语句级依赖图上收集被引用的定义，再用 PyCG 调用图补全跨文件调用，只把执行闭包交给合成模型，替代整仓或整文件供给，去掉同名无关函数的干扰。切片深度取 3 层，96.5% 的函数无缺失符号；合成上下文均值由约 2.4 万 token 降至约 9.6 千 token。  
**运行时插桩的真实调用样本采集**：在目标函数上挂 hook，记录真实调用的入参（展开默认值）、返回值、类型与调用者，超长值保留首尾各 90 字符，随合成请求附上最近几条记录，使测试输入取自真实调用，替代模型凭直觉构造的典型输入。有副作用的函数不启用采集；开启后边界输入覆盖相对提升约 20%，一次执行通过率再提升 2pp。  
**执行报错与未覆盖分支的多轮反馈**：一次生成难以同时满足可执行与覆盖率，改为逐轮只处理未达标函数：执行报错时回传异常栈与出错行，覆盖不足时回传未覆盖分支的位置与条件表达式，引导模型针对具体路径补用例。终止条件为分支覆盖率与达标函数占比均不低于 0.8；覆盖率达标率由首轮 45% 提升至第三轮 87%。  
**docstring 与已通过测试的规格提炼**：规格不照抄 docstring，改为以 docstring、签名与已通过的等价测试为材料重写，测试验证过的边界与异常行为直接成为规格中的示例与约定。任务包对模型只暴露签名与规格，判分测试隐藏；训练与评测集按仓库维度切分，并过滤与公开基准重叠的仓库，避免模型凭记忆源码得分。

#### 项目二：仓库级编码 Agent 长程轨迹的质量筛选与增强蒸馏
**项目背景**：仓库级编码任务要求 Agent 按整库规格在空工作区从零实现一个 Python 库，单条轨迹上百轮工具调用、数万 token；低质轨迹进入 SFT，会让模型学到连续写改不验证、未执行测试即宣告完成两类行为。项目对团队采集的 2,700 余条轨迹做导出校验、失败归因与两类增强，在 Qwen3-32B 上蒸馏 SFT 后，盲改次数下降 38%、接口签名错位率下降 62%、工具报错率减半。本人负责过程监督注入与压缩恢复样本合成，参与轨迹导出、失败归因与配比实验。  
**stream-json 轨迹的消息聚合与配对校验**：rollout 日志按 stream-json 逐块输出，同一轮的思考、文本与多次工具调用分散在多条记录里，直接转换会产生重复轮次与孤立的工具结果。导出时按 message id 合并同轮内容块，为全部消息重建全局索引，再校验每个 tool_call id 与返回结果一一对应，校验失败的轨迹整条剔除，约占 3%；后续归因与注入都依赖该索引定位到具体轮次。  
**失败断言到出错动作的三层归因**：低分轨迹只看总分无法区分环境问题与模型行为问题。先从判分输出取失败断言与报错位置，再沿全局索引回溯最后一次改动该文件的 Write 或 Edit，定位引入错误的轮次，最后归入九类失败模式，按出现频率与命中样本均分两列统计。归因显示自测与判分验证方式不一致覆盖几乎全部低分轨迹；未完成类出现次数少，但命中样本均分不足一成。  
**关键决策点的过程监督注入**：在成功轨迹的完成宣告、报错转修复、测试执行等九类决策点前置写入一段英文状态回顾，只写已完成什么、还差什么，不给操作指令，让模型学会判断任务状态，替代逐轮打结构化阶段标签。完成宣告点必注入，其余按调和平均式预算与最小间隔分配，平均每条 3 至 4 处，注入只改 content、不动 tool_calls 配对；训练后宣告完成前未执行任何测试的轨迹占比由 23% 降至 9%。  
**九段摘要模板的压缩恢复样本合成**：压缩后的模型常凭记忆直接编辑文件，或反复重读同一批文件。合成时在累积约 5 万 token 后、紧邻下一次重读或测试的轮边界切分，后段上下文改由九段有损摘要重建，覆盖主要诉求、文件与代码段、错误与修复、待办与下一步，恢复引导要求先确认再修改，且不得出现压缩、摘要等自指词。一批 130 余段样本工具调用配对零错位，学生最长盲改由约 8 轮降至约 4 轮。  
**增强样本配比扫描与长序列蒸馏 SFT**：学生全参 SFT，YaRN 把上下文扩到 128K，只对 assistant 消息计 loss，训练集由筛选后的成功轨迹与两类增强样本组成。增强样本占比扫描四档，超过三成后同类状态下的回复在两种风格间摇摆，取 25%；与初版数据同超参对照，盲改次数下降 38%，总分差异处于噪声量级。
