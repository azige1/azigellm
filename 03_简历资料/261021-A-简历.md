### 大模型智能体复杂任务长程规划技术研究（上海市专项，2025SHZDZX025G07） | 硕士研究生

#### 项目一：可执行环境规模化与长轨迹数据合成
**项目背景**：策略 RL 需要数量足够、可复位且判分可信的环境与任务，LLM 合成的环境常含语义错误，verifier 容易漏判未声明的状态改动，公开轨迹又多为单轮或短程。沿合成环境骨架重建环境校验、任务生成、verifier 与轨迹分流四个环节，产出 1,146 个可执行环境、10,860 道任务与 3.19 万条长轨迹，在 Qwen3.5-122B-A10B（122B 总参 / 10B 激活）上完成 SFT；held-out 环境 Pass@1 由 31.4 提升至 42.3。本人负责 verifier 构建与轨迹错误分流，参与环境校验与任务合成。  
**环境合成的来源轨迹回放校验**：coding agent 同时推断语义、编写实现与测试时，实现和测试会共同接受同一个错误。校验证据改为真实系统采集的交互轨迹，把生成的环境放回原始轨迹逐步回放并核对每步中间状态，替代自生成测试。1,480 个候选环境保留 1,146 个，独立抽检的工作流保真度由 77.8 提升至 90.6。  
**闭世界状态差分断言的 verifier 构建**：只检查目标字段的 verifier 放过额外改动，策略顺带写错无关记录仍能得满分。判定改在初末状态差分上执行声明式断言，差分中每处变化必须被某条断言解释或属于显式忽略字段，其余一律计为副作用，替代逐字段检查。人工抽检 500 条判定，verifier 误判率由 13.8% 降到 2.6%。  
**目标 DSL 判分与子目标锁存回放**：逐题编写的 Python verifier 难以静态检查，且只给终态 0/1，组内常无分差。判分改用五种算子的目标 DSL，任务编译时回放参考解确认可解；子目标在初态副本上只回放已提交的写操作并锁存，结果按完成、部分完成、错误宣告等六类输出，替代二值判分。SFT 模型的零方差组占比由 38.2% 降到 26.7%。  
**隐藏规则约束的欠指定任务合成**：随机组合工具生成的任务指令直白、ID 直接给出，隐藏规则几乎不被触发。生成时以回放校验中确认的隐藏规则作约束，要求参考解经过规则触发条件，并控制 ID 是否需要查询、目标是否存在歧义两个维度，同时拒绝初始状态已满足目标的候选。候选经质量门后入池 10,860 道，隐藏规则切片的 Pass@1 由 21.9 提升至 28.3。  
**错误片段分流的轨迹合成与 loss mask**：只保留一次成功的干净轨迹时，模型学不到报错后的恢复。teacher 轨迹按步标注环境故障、可纠正错误、未解决失败与编造四类，环境故障与编造整条剔除，可纠正错误留在上下文但屏蔽 loss，未解决失败由 teacher 从最后正确状态续写。4.64 万条入训 3.19 万条，报错后两步内恢复率由 46% 提升至 69%。

#### 项目二：长程多轮 GRPO 的信用分配与上下文窗口扩展
**项目背景**：SFT 后的模型在平均 31 轮的长程任务上常提前宣告完成，或在报错后重复调用，终局 reward 给不出中间决策的信用。以 Qwen3.5-122B-A10B 的 SFT checkpoint 为起点，在 6,720 道任务上做多轮 GRPO，重写 reward 与 step 级 advantage；held-out Pass@1 由 42.3 提升至 54.6，AutomationBench v1.0.6 由 37.6 提升至 45.3，ALE Overall 由 18.4 提升至 23.9。本人负责 teacher 调幅与 rubric reward，参与 reward 设计与扩窗。  
**终态记录的确定性 reward 与档位单调性**：reward 含回复文本判分时，策略学会未完成即宣告完成。reward 改为依据终态记录、状态差分与结构化事件，agent 的文字声明不进入评分；完成、未声明副作用、部分完成、合理放弃、截断、错误写入六档严格单调，替代人工调权的加权和，基础设施失败不产生梯度。未完成即宣告完成的轨迹占比由 18.6% 降到 6.4%。  
**teacher 调幅的 step 级 advantage 与退化组补偿**：环境回报只有轨迹级信号，单元素组与零方差失败组几乎不产生 step 级梯度。引入 Qwen3.5-397B-A17B 给出 step 级偏好：组内按 teacher log-prob 排名，单元素组用师生 log-prob 差经批内标准化后压界，只调整 advantage 幅度、不改变符号，替代无约束蒸馏。回报完全相同的失败组另加系数 0.1 的补偿项，Pass@1 提升 2.7。  
**规范化报错 anchor 的 GiGPO step 级分组**：GiGPO 按观测文本分组时，时间戳与记录 ID 使第二步之后几乎都是单元素组。改以去除 ID 与时间的规范化报错模板作 step 级 anchor，同一报错状态下的不同恢复动作进入同组比较，替代观测字符串匹配。单元素组占比由 94% 降到 58%，Pass@1 提升 1.8。  
**agentic rubric 的环境探查生成与文本产物 reward**：终态 reward 只检查文本字段是否写入，工单回复内容空洞仍判完成。rollout 前由 agent 只读探查初始环境，为含文本产物的任务生成冻结且对策略不可见的 rubric，替代逐题手写 verifier 与整篇 judge 打分；实体与数值条目编译为状态查询，语义条目由 judge 只看产物判定。完成档 reward 随 rubric 分变化并保持档位单调；文本切片 Pass@1 由 36.4 提升至 41.9。  
**轨迹窗口的分阶段扩展**：扩窗后失败轨迹比成功轨迹更早触顶，尾部负梯度放大并出现重复生成，而全程短窗口又使长任务大量截断。窗口由 64K 分三档扩到 128K，升档判据取成功轨迹长度高分位与截断率，升档后临时降低梯度裁剪阈值并开启重复检测，替代单次切到最大窗口。截断率由 11.3% 降到 3.6%。

#### 项目三：多 harness 评测协议与回退归因
**项目背景**：单次 rollout 的分差常小于评测噪声，只看终态的判分又放过过程违规，checkpoint 的涨跌无法归因。在多 harness 评测框架上建立版本固定、约束下判分、judge 校准、配对统计与回退归因五个环节，为 SFT 与 RL 各阶段提供统一验收口径；配对五遍协议把差值判定门限由 6.3pp 降到 0.9pp，judge 假阳性率由 7.4% 降到 1.8%。本人负责约束下判分与回退归因，参与 judge 校准与统计工具实现。  
**运行清单与 judge replay 的版本固定**：模型、harness、工具返回截断、环境快照、判分提示任一变化都会改变分数，事后无法区分版本漂移与能力变化。每次运行写入记录上述版本的运行清单并计算哈希，清单不一致的结果不进入对比；judge 升级时 replay 已存轨迹重判，替代重新 rollout。一次 ALE Overall 上 1.6 的提升经此定位为截断配置变化。  
**约束下成功率与调用顺序判分**：终态通过的轨迹可能写前未读取，或中途越权后再撤销。判分在终态检查之外增加工具调用先后顺序断言，以成功且全程未违规计通过，替代只看终态的成功率。RL 后成功率 54.6 对应约束下成功率 47.3，SFT 阶段为 42.3 与 33.1，两者差值主要来自写前未核对。  
**判分金标校准与 judge 解析修正**：rubric 判分的错误会直接写进 checkpoint 选择。以 600 条人工双标样本校准 judge，统计混淆矩阵与人际一致性差距，评测 judge 取与被测模型不同家族的 GLM-5，只看产物不看轨迹；解析层兼容围栏与包装 JSON，修复可解析答案被判失败的问题。judge 假阳性率由 7.4% 降到 1.8%。  
**配对差值门限与 task 级 bootstrap 检验**：480 题单遍独立比较时差值的区间半宽约 6.3pp，多数单项增益都低于这一水平。评测前按任务数、遍数与不一致率计算门限，固定五遍并按题配对，以 task 级 bootstrap 区间判定，低于门限的差异记持平，替代单次分数排序。门限降到 0.9pp 后，一项 0.7pp 的训练改动未被采纳。  
**单因素对照的回退归因与 harness 组件消融**：某 checkpoint 在 AutomationBench 上回落 2.4 而 held-out 上升，按噪声、评测设置、harness、训测差异、分布偏移、真实回退的顺序逐一设单因素对照，修正后下降消失才确认原因，定位为评测 harness 缺少日期上下文。另把 harness 拆成五个开关逐一移除，写前校验贡献最大，约 3.1pp。
